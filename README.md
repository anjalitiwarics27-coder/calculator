A neat, no-nonsense calculator that gets the job done — no frameworks, no bloat, just clean **HTML** and **CSS**. Perfect for quick calculations with a beautiful, distraction-free interface.

## 🚀 Getting Started

Run it locally in 3 easy steps:

```bash
# 1. Clone the repository
git clone https://github.com/anjalitiwarics27-coder/calculator.git

# 2. Move into the project folder
cd calculator

# 3. Open in your browser
open calculator.html
```

That's it — no installs, no setup, no waiting. 🎉
